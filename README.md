# 🧩 Proyecto JPA – Sistema Systech con Base de datos

Autores: Gabriela M. Guerrero Paiz, Steven L. Sequeira R., Allan R. V. Acuña O., Fernando G. Gazo G., Guillermo J. V. Vega.

Docente: José Durán García.

## 📘 Descripción General

Este proyecto tiene como objetivo aplicar los conceptos vistos en clase mediante el desarollo de un sistema CRUD sencillo en **IntelliJ IDEA**.
Para la gestión y persistencia de los datos, el proyecto utiliza **JPA (Java Persistence API)** junto con **Hibernate** como proveedor de implementación.  
La aplicación se conecta a una base de datos **PostgreSQL**, lo que permite **almacenar y conservar los datos de manera persistente** incluso después de cerrar la aplicación.  El manejo de la conexión y las operaciones de persistencia se realiza mediante un archivo `persistence.xml` configurado dentro del proyecto.

---

## 🧠 Objetivos del Proyecto

- Aplicar los conceptos de **POO**, **persistencia** y **relaciones entre entidades**.  
- Implementar un proyecto modular y legible en **IntelliJ IDEA**.  
- Desarrollar operaciones sobre las entidades.  
- Practicar el uso de **control de versiones con Git y GitHub**.
